# ECHO Design Studio

A modern frontend project for a design studio experience built with TypeScript, CSS, and JavaScript.

## Overview

ECHO Design Studio is a web-based project focused on creating polished, responsive, and visually engaging interfaces. This repository is structured for a design-forward application and is ready to be extended with components, pages, and styling systems.

## Tech Stack

- TypeScript
- CSS
- JavaScript
- Modern frontend tooling

## Features

- Responsive UI for desktop and mobile experiences
- Reusable design-oriented component structure
- Clean separation between structure, styling, and behavior
- Scalable project layout for future enhancements

## Getting Started

1. Clone the repository
2. Install dependencies
3. Start the development server

```bash
git clone https://github.com/Jishnu09-siuu/ECHO-Design-Studio.git
cd ECHO-Design-Studio
npm install
npm run dev
```

## Available Scripts

```bash
npm run dev
npm run build
npm run start
```
